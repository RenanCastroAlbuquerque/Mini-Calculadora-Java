# Mini Calculadora em Java
Sobre o projeto

Mini calculadora desenvolvida em Java utilizando JOptionPane para entrada e exibição de dados.

O projeto foi criado com o objetivo de praticar:

Estruturas condicionais (if / else)

Comparação de Strings com .equals()

Conversão de tipos (String para double)

Operações aritméticas básicas

Funcionalidades

Soma

Subtração

Multiplicação

Divisão

Tratamento para operador inválido

Tecnologias utilizadas

Java

Biblioteca javax.swing.JOptionPane

Objetivo

Praticar lógica de programação e tomada de decisão em Java, reforçando conceitos fundamentais para construção de aplicações mais complexas.
